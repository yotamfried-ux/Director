# QA before delivery

Run in this order; report what passed and what was not checked.
1. `npx tsc --noEmit` (compositions typecheck).
2. Stills at key frames (hook, each transition, each scene mid, outro) → contact sheet with PIL → look at it. Check: Hebrew RTL, no clipped text, scenes not stuck to the top half, captions not wrapping badly, no overlapping ghost layers.
3. Mid-transition frames (blurred overlaps are expected, but nothing should look broken).
4. Final file: `ffprobe` → H.264 Main L4.0, yuv420p, AAC LC, 1080x1920 (phone) or 1280x720 (site), expected duration, size < 16 MB.
5. `scripts/qa.sh <slug> <video>` OCR of `must_appear_text` for the first-generation promo; for Showcase check captions by eye on stills.
6. Not verifiable by the agent: sound quality, beat alignment, how WhatsApp or the live site renders it → say so and ask Yotam to check.
