1. For each active product in `products/registry.json`: check the repo (REST `gh api repos/<repo>/commits|releases|issues`, last 24h) and note changes worth content.
2. Triage new inbound leads from the private store (if connected): classify, draft a reply (Hebrew), mark follow-ups due. Do not send.
3. List posts waiting for approval and approvals older than 3 days.
4. Report: <=8 lines. Nothing else.
