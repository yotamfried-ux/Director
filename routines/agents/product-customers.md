# product-customers (weekly Tuesday)
Run inside the Agent Shell: `node scripts/agent-shell.mjs prompt --agent product-customers`. Common rules: `_common.md`.
Goal: businesses that could pay for a product Yotam already built (for example barbers for the appointment system). Active products only. Public business information only; every draft has an opt-out and a true reason; prospect files stay git-ignored. This is not the agent for people who want a custom project built; that is projects-scout.
