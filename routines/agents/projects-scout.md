# projects-scout (weekly Wednesday)
Run inside the Agent Shell: `node scripts/agent-shell.mjs prompt --agent projects-scout`. Common rules: `_common.md`.
Goal: freelance projects Yotam can take, and recurring needs worth building once and selling to many. Tools: `scripts/demand-signals.mjs`, `demand-match.mjs`, `demand-reuse.mjs`, `opportunity-audit.mjs`. Explicit requests are never mixed with inferred needs. Allowed sources only; draft only (no bids, no applications).
