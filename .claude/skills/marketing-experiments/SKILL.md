# Marketing experiments

- Log every meaningful variation in `experiments/log.md` using `experiments/template.md`: hypothesis, variant(s), what changed, evidence (Yotam's feedback or metrics), decision.
- Qualitative evidence from Yotam counts but must be quoted briefly; measured data (views, watch-through, clicks, replies, leads) comes only from official channel analytics once publishing exists.
- After each experiment: update `docs/06-lessons-learned.md` and the relevant skill, so the rule lives where the agent will read it.
- Design real tests when channels exist: one change at a time, same audience, pre-stated success metric (Engineering-OS `docs/product-experience/analytics-experimentation-growth.md`).
- Don't over-claim: one friend's opinion or n=1 chat is a signal, not a result.
