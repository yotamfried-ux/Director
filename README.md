# Director

סטודיו השיווק והתוכן של יותם: סוכן (Claude) שמייצר סרטוני תדמית למוצרי התוכנה שלו, קליפים לאתרים, תוכן לרשתות, ובהמשך מפרסם (באישור) ומנתח נתונים. הריפו הוא הזיכרון והארגז כלים של הסוכן, ומשתפר דרך ניסויים.

An agent-operated marketing & content studio for Yotam's software products. Start with `CLAUDE.md`.

## Quick start
```bash
npm ci
npx remotion studio                       # preview
bash scripts/render-showcase.sh           # 9:16 phone/WhatsApp promo with music -> out/showcase/whatsapp.mp4
bash scripts/render-site.sh               # silent 16:9 site clips (he/en) -> out/site/
```
Reference product: **Tori** (`products/tori.md`). Latest approved phone video: `products/tori-script-v6.md`.
